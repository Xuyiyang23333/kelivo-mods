# 当前状态与后续方向

## 当前基线

当前采用**精简实用方案（方案 A）**，用户已确认真机功能正常，作为稳定可用版本保留。

- **已移除**：逐应用签名白名单、批准状态机、聊天与通知批准入口、Mods 页已批准应用列表、首次隐私弹窗、本地审计日志和 `QUERY_ALL_PACKAGES` 权限。
- **已保留**：独立 `PhoneAgentService`、节点路径重解析、密码节点过滤与截图密码区域涂黑、系统敏感入口硬基线、电话/短信角色保护和前台可视化叠加层。
- **已补齐**：`phone_agent_input` 支持 `wait`、`list_apps` 和 `open_app`；坐标手势不依赖前置截图；观察侧不再因 `windows` 列表短暂滞后阻断普通应用。
- **文档口径**：`docs/phone-agent-plan.md` 只保留当前架构、契约和维护方式；历史里程碑与验收流水账从 Git 历史查阅，不再同步维护多份状态记录。

## 后续方向

1. 以当前版本为稳定基线，后续改动保持小步提交，避免再次形成跨多子系统的大规模未提交差异。
2. 只在真实使用暴露问题时微调，例如应用启动后的稳态等待、节点树输出和模型提示词。
3. 不再需要与主线 `com.psyche.kelivo` 共存测试时，可评估移除 `patches/application-id.patch`。
